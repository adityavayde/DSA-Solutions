## 📝 Problem Statement

You are given an **unsorted array arr[]** of integers that may contain duplicates. Your task is to **remove the duplicate elements** , keeping only the **first occurrence** of each element, and return the resulting array.

### Example 1:

**Input:** arr = [1, 2, 3, 1, 4, 2]

**Output:** [1, 2, 3, 4]

**Explanation:**

1 and 2 are repeated; only their first occurrence is kept.

### Example 2:

**Input:** arr = [1, 2, 3, 4]

**Output:** [1, 2, 3, 4]

**Explanation:**

No duplicate elements found.
